sketchy is an open-source agent skill. Ask Claude Code, Codex, Cursor or Gemini CLI for a deck, a lesson, a report or a chart, and it draws one in pencil: graphite on blue-gray paper, the key number in red and every figure in typewriter type. The result is one HTML file that works offline and exports to PDF, PowerPoint and MP4.

One line, any agent

npx skills add OthmanAdi/sketchy

Then ask in plain words: “make a 10-slide board update from this spreadsheet”, “explain how DNS works for a class of 15-year-olds”, “turn these numbers into a one-pager for the CFO”.

Claude Code, Codex, Cursor, Gemini CLI, Windsurf, Cline and more. Every install route.

What it makes

Every example is one HTML file. Open it, press o for the overview and s for sound.

How a build runs

Brief

The one sentence to remember, the decision afterwards, where each number comes from.

Deal a style

Paper, cover, pencils and opening page, never the same as your last ten.

Draw

Templates, more than 100 sketches, charts from specs, sound from a seed.

Check by looking

A linter, screenshots of every page, and a reviewer that has not seen the code.

Sound, if you want it

Off until the viewer turns it on. Pencil scratches, page turns, rubber stamps and generative music, all synthesised in the browser. The same deck always gets the same piece, so the video soundtrack matches the live one.

Your paper, your pencils

Six papers ship: day sketchbook, night ledger, kraft, blueprint, graph and cartridge. Drop your own theme or template into ~/.sketchy/ and sketchy uses it first.
